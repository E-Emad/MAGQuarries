## 🎯 لماذا صُمم MAGQuarries ERP؟ (حل الفجوة التشغيلية)

في قطاع استخراج الخامات والتعدين، تفشل البرمجيات المحاسبية العامة (مثل SAP, Odoo, QuickBooks) لأنها تفترض وجود اتصال إنترنت دائم، ومكاتب مكيفة، ودورات مبيعات نمطية. في المحاجر، **تُحسم الأرباح عند كابينة الميزان، وعلى ذراع اللودر والبلدوزر، وفي دقة احتساب إتاوة الأرض وعجز كميات الرفع الشبكي**.

يعالج نظام **MAGQuarries** أهم 6 مشاكل تستنزف أرباح المستثمرين:
1. **التلاعب بالأوزان والشاحنات:** القضاء التام على الشحنات غير المسجلة وسرقة الخامات عبر التدقيق الديناميكي لوزن الفارغ، وباركود البونات المشفر.
2. **فقدان هوامش الربح:** تطبيق **محرك التسعير المزدوج (Dual-Pricing)** للفصل الدقيق بين سعر التكلفة/المحجر وسعر العميل واحتساب صافي هامش الربح لحظياً.
3. **نزاعات مقاولي اللوادر والبلدوزرات:** محرك احتساب فريد يدعم صيغة **(المتر والساعة معاً)** مع الخصم التلقائي لكافة السلف والعهد التشغيلية بنظام FIFO.
4. **عجز كميات الرفع المساحي الشبكي:** مقارنة الكميات المقاسة مساحياً بالجبل مع ما تم وزنه على البوابة واحتساب غرامات النقص آلياً.
5. **نزاعات الشركاء والمستثمرين:** **جدار عزل مالي صارم (Strict Isolation)** يمنح كل شريك شفافية كاملة على محاجره فقط دون كشف بيانات باقي المستثمرين.
6. **انقطاع شبكات الإنترنت بالمناطق الجبلية والصحراوية:** معمارية **(Offline-First)** تسمح للميزان بالعمل 24/7 دون أي توقف، مع المزامنة الآلية فور عودة التغطية.

## 🌟 الميزات الجوهرية بالتفصيل

### ⚖️ 1. كابينة الميزان والشاحنات (Weighbridge Management)
- وزن ثلاثي دقيق: (القائم - الفارغ = الصافي) خلال أقل من 5 ثوانٍ للشاحنة.
- منع التلاعب بوزن الفارغ بمقارنة الوزن الحالي بالسجل التاريخي للشاحنة.
- إصدار بونات حرارية فورية مشفرة بـ QR Code لمنع تزوير البونات.
- ربط فوري بسقف الائتمان للعميل لمنع تفريغ أي حمولة لحساب عميل مدين.

### 💰 2. محرك التسعير المزدوج (Dual-Pricing Architecture)
- الاحتفاظ بسعرين مستقلين لكل خامة: **سعر تكلفة المحجر والإتاوة** مقابل **سعر البيع التجاري للعميل**.
- حساب هامش الربح الصافي الفوري لكل شاحنة خارجة من البوابة.
- حماية سرية الأسعار ومنع مدخل البيانات الميداني من الاطلاع على هوامش الربح.

### 🚜 3. أسطول المعدات ونظام الاحتساب المزدوج (المتر والساعة معاً)
- إمكانية محاسبة مقاولي اللوادر والبلدوزرات بالمعادلة المركبة:  
  $$\text{التكلفة} = (\text{الأمتار المكعبة} \times \text{سعر المتر}) + (\text{ساعات التشغيل} \times \text{سعر الساعة})$$
- استقطاع سلف المحروقات والسولار وقطع الغيار آلياً بنظام **الأقدم أولاً (FIFO)** دون أي تدخل يدوي.
- تقارير كفاءة استهلاك الوقود لكل ساعة عمل أو متر مستخرج.

### 📐 4. مطابقة الرفع المساحي الشبكي وعجارة الأرض
- مقارنة كميات الرفع الطبوغرافي لمكعبات الجبل مع مبيعات الميزان المسجلة.
- رصد أي خامات غير مقيدة على الميزان وتطبيق شروط الحد الأدنى للإنتاج آلياً.
- تصفية استحقاقات ملاك الأراضي وعجارة الموقع بمنتهى الدقة.

### 🤝 5. حوكمة الشركاء والعزل الصارم (Multi-Partner Strict Isolation)
- عزل مالي تام لكل محجر كمركز ربحية مستقل (Profit Center).
- لوحة تحكم مخصصة لكل شريك يرى من خلالها إنتاج ومبيعات وأرباح محاجره فقط.
- تجميع تكاليف التشغيل السداسية (الخام، الإتاوة، المعدات، الرواتب، الوقود، المصروفات الميدانية) لحساب صافي الربح الدقيق القابل للتوزيع.
- سجل شفاف للمسحوبات وتغذية رأس المال الاستثماري.

### 🤖 6. المحاسب الآلي والتسويات الدورية (Auto-Settlement Engine)
- إغلاق فترات المحاسبة وتوليد كشوف الحسابات المعتمدة بضغطة زر واحدة لمقاولي المعدات، موردي الخامات، والشركاء.
- توفير مئات الساعات المهدرة في إعداد كشوف الحسابات اليدوية.

### 🔄 7. إلغاء الاعتمادات الآمن والتصحيح اللحظي (Intelligent Financial Reversibility)
- إمكانية فك اعتماد أي نقلة أو مصروف معتمد عند حدوث خطأ بشري ميداني.
- إلغاء وعكس القيود الدفترية آلياً، ورد النقدية، وفك حجز السلف دون ترك أي سجلات معلقة أو مشوهة للدفاتر.
- سجل تدقيق غير قابل للتعديل يوثق من قام بالتعديل وسببه وتوقيته.

### 📡 8. معمارية العمل دون إنترنت (Offline-First Resilience)
- استمرار تسجيل الشاحنات بالميزان وإصدار البونات في أعتى مناطق الصحراء المعزولة.
- مزامنة خلفية تلقائية بمجرد التقاط إشارة الشبكة دون تعليق النظام أو تكرار أي قيد مالي.

## 👥 7 لوحات تحكم متخصصة (Role-Based Dashboards)

| لوحة التحكم | المستخدم المستهدف | القيمة التشغيلية والوظيفية |
| :--- | :--- | :--- |
| **لوحة الإدارة التنفيذية** | رئيس مجلس الإدارة / المدير التنفيذي | مراقبة مؤشرات الربحية المجمعة، رصيد السيولة، وإنتاجية المحاجر لحظة بلحظة. |
| **لوحة المحاسب المالي** | المدير المالي والمحاسبون | إدارة سندات الصرف والقبض، إعداد التسويات، ومراقبة البنوك والخزائن. |
| **لوحة المراقب الميداني** | فرق التفتيش ومكافحة التلاعب | رصد فروق الأوزان المشبوهة، الحركات الليلية، ومراجعة سجلات التدقيق. |
| **لوحة مدير الموقع** | المهندس المقيم ومدير المحجر | متابعة حركة الشاحنات بالساعة، مخزون الخامات المكسرة، وتوزيع المعدات. |
| **لوحة مشرف الميدان** | مشرفو المعدات والتشغيل | تسجيل يوميات وساعات عمل اللوادر والبلدوزرات وقراءات العدادات. |
| **لوحة كابينة الميزان** | مشغلو الميزان والوزانون | شاشة سريعة جداً لإصدار بون الوزن في ثوانٍ مع العمل دون إنترنت. |
| **بوابة الشريك المستثمر** | الشركاء وأصحاب الحصص | متابعة أرباح ومسحوبات وإنتاج المحجر الخاص بالشريك فقط بأمان تام. |
